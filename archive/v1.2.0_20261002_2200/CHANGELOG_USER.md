# Vditor 编辑器 更新记录（用户版）

- **应用名称**：Vditor 编辑器
- **当前版本**：**1.2.0**
- **适用平台**：飞牛 fnOS（NAS）应用中心 ／ Android 手机与平板
- **版本说明**：`4.0.x` 为早期测试版（文件名带 `-beta`）；从 **1.0** 起为正式版。

> **📌 维护约定**
> 本文（用户版）与开发者版 `CHANGELOG.md` 必须保持同步。
> **后续发布任何新版本时，需同时更新这两份更新记录。**

本记录按时间从新到旧排列，覆盖自首个测试版到当前正式版的全部版本。以下只说明「发生了什么变化」。

## 1.2.0（2026-10-02）

> 本版本为**大版本**：新增手机 / 平板客户端。浏览器端的功能与设置**完全没变**，照常使用即可。

**新增**
- **推出手机与平板客户端（Android）**，安装包约 1.4 MB，可直接在手机上安装使用。
- 手机端可以：浏览与切换文档分区、逐层进入目录、新建文档、编辑 Markdown、自动保存、查看与回滚历史版本、上传并插入图片等附件、删除文档。
- 登录时**两种地址都支持**：局域网填「IP:端口」（如 `192.168.1.10:9000`，端口可省略），公网填域名（如 `vditor.example.com`），再输入访问密码即可。
- 勾选「记住地址」后，下次打开自动填好地址，并会记住最近用过的 5 个地址，点一下就能选。**出于安全考虑不保存密码**，每次仍需输入。
- 支持跟随系统的深色模式，界面在手机、平板与横屏下均能正常显示。

**优化**
- 同一篇文档在多处（如手机和电脑）同时编辑时，保存前会检查是否已被他人改动，若已改动会先提示你确认，**不会在你不知情的情况下覆盖别人的内容**。
- 网络偶发中断时会自动重试；若确实连不上，会明确提示「请检查与服务器的连接」并提供重试按钮，而不是只显示一片空白。
- 附件上传前会先检查格式与大小是否超限，不合格时立刻说明原因，不会白等一场。

**修复**
- 修复「退出登录」在登录状态已失效时会报错弹窗的问题，现在无论何种状态都正常退出。

**更改**
- **手机客户端需要服务端升级到 1.2.0 或更高版本**才能使用。1.1.x 的服务器没有手机端接口，浏览器端不受影响、照常使用。
- 浏览器端的界面、功能、设置项与配置文件格式**全部保持不变**，从 1.1.4 升级上来无需任何额外操作。

## 1.1.4（2026-10-02）

**修复**
- 修复在极少数特殊网络环境下，**上传文件、替换站点图标、恢复备份**这三个操作会出现「点了没反应、页面像是断开了」的情况。现在遇到这种情况会正常给出提示，不再出现空白响应。
- 修复「添加」「恢复默认」两个按钮位置偏低、与输入框没有对齐的问题，现在三者处在同一水平线上。
- 修复点「恢复默认」后**保存不了设置**的问题：默认列表里有一项带连字符的格式（appref-ms），此前会被判定为「填写不合法」而使整次保存失败，现在可正常保存。
- 修复上传含连字符的格式（如 appref-ms）后**文件取不到**的问题：现在上传后能正常打开和下载。
- 修复默认拦截列表被少算一项的问题，实际拦截条目为 68 项。

**优化**
- 站点图标的大小上限单独设为 4 MB，避免误传超大图片。
- 应用内部做了整体瘦身与整理，删掉了用不到的内容，安装包比之前略小一点（约 4.6 KB）。**功能、设置项、配置文件格式全部保持不变，升级后无需任何额外操作。**

## 1.1.3（2026-10-02）

**修复**
- 修复**上传功能实际无法使用**的问题。1.1.2 版本中上传入口会被拦住，任何格式的文件都传不上去；现已恢复正常，各种格式均可上传。
- 修复上传格式限制调整后**不生效**的问题，现在保存后立即按新设置执行。
- 修复把限制条目**全部删除后又被自动填回默认内容**的问题，现在删除即彻底删除。

**新增**
- 上传格式限制改为**黑名单**：默认放行一切，仅拦截可执行文件、脚本等高风险类型（可执行程序、批处理、脚本、网页文件等 67 项）。
- 「不允许上传的文件格式」改为**可逐条增删的列表**：填入扩展名点「添加」即可新增，点条目上的「×」即可删除；另提供「恢复默认」一键还原。
- 上传文件大小上限可在 1–512 MB 之间自由调整，默认 256 MB。

**优化**
- 「不允许上传的文件格式」的输入框与设置页其他输入框（网页标题等）**样式与交互完全一致**，不再显得突兀。
- 上传被拒绝时会明确提示是哪个格式被拦截、哪些输入不合法。

**更改**
- 上传限制的配置在重启应用后依然保持，无需重新设置。
- 由旧版本升级时，无需任何手动操作，原有配置会自动补齐默认拦截列表。

## 1.1.2（2026-10-02）

**新增**
- 新增「上传设置」：可分别设置单个文件的大小上限（1–512 MB，默认 256 MB）和允许上传的文件类型（留空表示不限制）。
- 「网络访问安全」中的「信任反向代理」与「强制 Cookie Secure 标记」两项改为**默认开启**；若手动关闭，会弹出确认提示，避免误关。

**修复**
- 关闭「强制 Cookie Secure 标记」后，通过公网 HTTP 访问时，登录后进行操作仍会提示未登录、无法正常使用的问题。

**更改**
- 上传不再限定固定的文件类型，默认不限制格式。
- 单个上传文件的大小上限由原来的 10 MB 提升为默认 256 MB（可在设置中调整）。
- 上传的网页类文件（如 HTML）不再被浏览器直接当作网页打开，改为需要下载后查看，更安全。
- 外观设置中的「暗黑模式」更名为「深色模式」，相关说明移到选项下方。
- 更新网页图标说明：此处仅控制浏览器中的网页标题与图标，不影响飞牛系统内显示的应用名与图标。
- 卸载引导说明重写：明确是否清除数据以应用内设置中的选项为准，且 Markdown 文档无论如何都不会被删除。
