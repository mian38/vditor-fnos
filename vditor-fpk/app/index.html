默认勾选。强制通过 HTTPS 传输登录凭证，避免 HTTP 明文被抓包窃取。外网访问时建议保持开启，需自行解决 HTTPS 访问环境，局域网直连 HTTP 可正常访问，不受影响。关闭后，公网 HTTP 也可正常登录使用，但安全性降低。

备份与恢复

两种备份与恢复的区别：

① 导出 / 导入备份（配置 + 文档）：生成 .tar.gz 完整快照，内含全部 Markdown 文档内容，以及配置文件（登录密码、Web 设置、上传文件、历史版本缓存等），完整备份应用所有内容，恢复即用。
适用场景：整机迁移、换设备、防灾容灾、需要把文档内容整体带走或恢复时使用。

② 导出 / 导入配置（JSON）：仅导出 Web 本设置页面各项（不含文档内容、登录密码、历史版本缓存等），体积小、便于阅读与编辑。
适用场景：想把偏好设置（版本策略、自动保存间隔、代理 / 安全选项、网页标题与图标等）快速迁移到另一个 Vditor 实例，或单独备份设置时使用。

一句话：要搬文档用①，只搬这个设置项用②；两者互补，建议定期同时备份。

关于本应用

Vditor 编辑器 是一个运行在 NAS 上的轻量级在线 Markdown 文档工具。 采用非 Docker 部署，由系统进程直接运行；后端仅使用 Python 标准库， 零第三方运行时依赖，文档直接以 Markdown 文件形式存放在你指定的 NAS 目录中， 可经 SMB / FTP 直接访问，数据完全自主掌控。

使用指南

一、编辑器（中间区域）

支持三种模式：点工具栏「编辑模式」可在 即时渲染 / 所见即所得 / 源码 之间切换；工具栏还提供加粗、斜体、标题、列表、引用、代码块、表格、链接、表情等常用操作。

点「上传」可插入图片或文件（需登录）；上传物保存在当前文档所在文件夹内，并以相对链接引用，便于随文档整体打包。在 HTTPS 环境下额外支持「录音」。左侧「大纲」自动列出文档标题，点按即可跳转。

二、文件与分区（左侧栏）

左侧按「分区」列出各 NAS 文件夹下的 Markdown 文件，选文件即打开。分区（即文档存放位置）在「设置 → 分区」中添加与管理；顶栏「«」按钮可折叠 / 展开左侧文档栏。

三、保存与自动保存

编辑后点右上角「保存」即可存盘，内容也会按设置的间隔 自动保存。自动保存间隔、是否保留历史版本在「设置 → 版本与自动保存」中配置。

四、历史版本

点顶栏「信息」按钮，在弹出的「文档信息」对话框中点「历史版本」即可查看每次保存的快照，支持 对比差异、恢复、删除；每个文件保留的最大版本数可在设置中调整（1–200）。

五、导出

顶栏「导出 .md / 导出 HTML」导出当前文档：若该文档文件夹内还有图片 / 音频等其它文件，会自动把整个文件夹打包为 zip 一起导出，否则只导出单文件。「设置 → 维护」里还有「导出备份（配置 + 文档）」与「导出 / 导入配置（JSON）」，用于迁移与容灾。

六、设置

顶栏「设置」打开设置面板，顶部为选项卡：
分区：管理现有分区（可隐藏 / 恢复系统默认分区、删除自建分区），并在其中添加新的 NAS 目录作为分区。
文件：历史版本开关与保留数量、自动保存间隔，以及上传大小上限与格式黑名单。
安全：网络访问安全（信任反向代理、强制 Cookie Secure）与修改登录密码。
外观：暗黑模式、网页标题、网页图标（浏览器标签页）。
维护：导出 / 导入备份（配置 + 文档）、导出 / 导入配置（JSON）、「状态与日志」（应用状态 / 应用日志 / 登录日志），以及「卸载时是否清除软件数据」。
关于与帮助：使用指南、快捷键一览（与使用指南并列的「快捷键」按钮，均以弹窗打开）、开源协议与法律声明。

七、账号与访问

首次进入需设置管理员密码，之后凭密码访问。忘记密码：请在 fnOS 终端中执行命令 vditor reset-password，按指引重置密码。

八、字数统计（顶栏）

正文：渲染后读者实际看到的文字数（不含 Markdown 标记）；含语法：Markdown 源文件字符数（磁盘实际大小）；预计阅读时间：正文字数 ÷ 400（字/分钟，向上取整），仅作粗略参考。
