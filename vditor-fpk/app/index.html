现有分区管理

此处列出本应用当前可用的文档分区，含系统默认分区路径。可对系统默认分区执行「隐藏」（不删除对应目录文件，仅是本应用不再显示），隐藏后可执行「恢复」；对在应用内添加的分区可执行「删除」。

添加分区

在此添加 NAS 上已有的目录作为文档分区，各分区互相独立、互不混淆，可添加多个并为每个分区指定显示名。
若要自定义目录，需同时在 fnOS 系统「应用中心 → 已安装 → Vditor 编辑器 → 访问权限」中授权对应目录。

渲染模式

本项保存后长期生效，对所有文档生效。超大文档的读写表现，与使用的设备和浏览器性能强相关。若本应用运行在性能较弱的设备或浏览器上，建议优先选用「自动」或「始终纯文本」模式。若只想临时切换当前编辑的大文档的渲染模式，请用顶栏右上角的「纯文本 / 富文本」切换按钮——该按钮仅在打开大文档时出现，切换只在本次会话有效，刷新后行为即回到本设置。

⚠️ 风险自负：对超大文档强制使用富文本渲染，可能造成浏览器长时间卡顿甚至无响应。如有打开超大文档的需求，请谨慎选择「始终富文本」模式。如坚持选择，开发者不对由此产生的任何数据损失与损坏承担责任。若遇卡顿，请使用顶栏的「纯文本」切换按钮切换回纯文本模式，并将此项改回「自动」或「始终纯文本」。

文件版本与自动保存

开启后，编辑内容会按下方设定的间隔定期自动存盘，无需手动点「保存」。关闭后不再自动存盘，但仍可随时用顶栏「保存」按钮或 Ctrl / Cmd + S 手动保存；关闭页面时若检测到有未保存的内容，仍会照常提醒，不会静默丢失。

两次自动保存之间的等待时间。间隔越短，未保存内容丢失的风险越小，但触发保存的频率也越高。

开启后，每次保存（手动或自动）都会生成一份可回溯的历史快照，可用于对比差异、恢复误改前的版本、删除旧快照。关闭后不再生成新的历史快照，已有的历史版本仍可查看与恢复。单个文档超过 5 MB 时，为避免高频自动保存影响性能，自动保存不生成历史版本，但手动保存仍正常生成历史版本。

每个文档各自独立计数，默认值为 50。超出上限后，最旧的快照会被自动清理。数值越小占用磁盘越少，数值越大可回溯的时间跨度越长。

网络访问安全

默认勾选。从 X-Forwarded-For 取真实客户端 IP，用于判断网络环境、登录日志显示、防爆破计数与会话绑定。仅在确实经由反向代理 / 内网穿透访问时才应开启；直连访问时开启会让他人可伪造该头，进而影响上述判定。

默认勾选。开启后，公网 HTTP 连接（如 http://公网IP:3838）将被拒绝访问，避免 HTTP 明文在公网中被抓包窃取。局域网 HTTP 连接（如 http://局域网IP:3838）可正常访问，不受影响。

本应用本身为纯 HTTP 服务，不提供 HTTPS，无法使用 https://公网IP:3838 直连访问（这与是否开启 Cookie Secure 无关）。如需通过 HTTPS 连接访问，请通过反向代理 / 内网穿透等方案实现 HTTPS，并务必开启上方两项安全选项。

⚠️ 风险自负：关闭「强制 Cookie Secure 标记」后，若使用 HTTP 连接访问，任何能访问到本服务地址的人，都可能截获你的登录密码与全部文档内容，安全性显著降低。请务必确认所处网络环境可信。如坚持关闭，开发者不对由此产生的任何数据泄露或损失不承担责任。

在使用本应用过程中，建议定期对数据进行备份。此处提供两种应用数据的导出 / 导入功能，可按需使用。

① 导出 / 导入备份（配置 + 文档）：生成 .tar.gz 完整快照，包含添加的分区内全部内容（包括 .md 文件、文件夹内原有及上传的附件、历史版本等），以及配置文件（登录密码、Web 设置等）。完整备份应用所有内容，恢复即用。可能需要较长时间。

适用场景：想把偏好设置（版本策略、自动保存间隔、代理 / 安全选项、网页标题与图标等）快速迁移到另一个 Vditor 实例，或单独备份设置时使用。

关于本应用

Vditor 编辑器 是一个运行在 NAS 上的轻量级在线 Markdown 文档工具。 采用非 Docker 部署，由系统进程直接运行；后端仅使用 Python 标准库， 零第三方运行时依赖，文档直接以 Markdown 文件形式存放在你指定的 NAS 目录中， 可经 SMB / FTP 直接访问，数据完全自主掌控。

使用指南

一、编辑器（中间区域）

支持三种模式：点工具栏「编辑模式」可在 即时渲染 / 所见即所得 / 源码 之间切换；工具栏还提供加粗、斜体、标题、列表、引用、代码块、表格、链接、表情等常用操作。

点「上传」可插入图片或文件（需登录）；上传物保存在当前文档所在文件夹内，并以相对链接引用，便于随文档整体打包。在 HTTPS 或 localhost 环境下额外支持「录音」（浏览器仅在这两种情形开放麦克风）。左侧「大纲」自动列出文档标题，点按即可跳转。

二、纯文本模式与大文档（1.3.0 起）

富文本渲染的成本与文档的块级结构数量成正比，因此对话记录、日志这类「体积不大但结构极多」的文档（实测 1.4MB 含 674 个代码块、1,450 个标题）在富文本模式下打开会卡死。本应用因此引入纯文本模式：关闭渲染、直接编辑 Markdown 原文，保存、历史版本、导出等能力全部保留，仅失去排版预览。

自动切换：打开体积超过约 500KB 的文档会自动进入纯文本模式，15MB 级超大文档亦可正常编辑。纯文本模式下顶栏会显示一条提示，并隐藏富文本工具栏。

顶栏切换按钮：打开大文档时，右上角会出现「纯文本 / 富文本」按钮（打开常规小文档时该按钮隐藏）。点它可临时切换当前文档的渲染模式：切回富文本时若文档过大会有二次确认，因为渲染可能明显卡顿。该切换只在本次会话有效、不写入配置，刷新页面后即恢复。

超大文档打开确认（超过 10 MB）：体积超过 10 MB 的文档，在左侧列表中会以橙色体积标签标出，点开时需原样输入文档名才能打开。这是为了防止误点后浏览器长时间无响应、看起来像应用崩了。若只是查看或编辑内容，建议打开后先用顶栏的「纯文本」按钮，此类文档本就不适合富文本渲染。

默认行为：「设置 → 文件 → 渲染模式」可长期指定默认行为，三选一：自动（推荐）（按上述阈值自动分级）、始终富文本、始终纯文本。判定优先级为「顶栏临时切换 > 默认行为 > 按大小自动分级」。

为让超大文档在纯文本模式下也能保持流畅：进入纯文本时会释放富文本引擎占用的内存，切回时再惰性重建；字数统计改用采样估算（超大文档只统计前 20 万字再按比例外推），因此顶栏字数在超大文档上是估算值，略有误差属正常。

三、文件与分区（左侧栏）

左侧按「分区」列出各 NAS 文件夹下的 Markdown 文件，选文件即打开。顶栏「«」按钮可折叠 / 展开左侧文档栏。

系统分区只有一个：/vol1/@appshare/vditor-docs，其文件可直接在文件管理器中访问。如需使用其它 NAS 目录，请到「设置 → 分区」中添加为自建分区（可添加多个，各分区文档相互独立）。

四、保存与自动保存

编辑后点右上角「保存」即可存盘（快捷键 Ctrl / Cmd + S）。若在「设置 → 文件」中开启了「启用自动保存」，内容还会按设定的间隔自动存盘，无需手动点保存；关闭自动保存不影响手动保存，关闭页面时若确有未保存内容也仍会照常提醒。

五、历史版本

点顶栏「信息」按钮，在弹出的「文档信息」对话框中点「历史版本」即可查看每次保存的快照，支持 对比差异、恢复、删除；是否生成历史版本、每个文件保留的最大版本数可在设置中调整（1–200）。单个文档超过 5 MB 时，为避免高频自动保存影响性能，自动保存不生成历史版本，但手动保存仍正常生成历史版本。

六、导出

顶栏「导出 .md / 导出 HTML」导出当前文档：若该文档文件夹内还有图片 / 音频等其它文件，会自动把整个文件夹打包为 zip 一起导出，否则只导出单文件。「设置 → 维护」里还有「导出备份（配置 + 文档）」与「导出 / 导入配置（JSON）」，用于迁移与容灾。

关于导出备份的耗时：已经开始打包，打包内容包含添加的分区内全部内容（包括 .md 文件、文件夹内原有及上传的附件、历史版本等），以及配置文件（登录密码、Web 设置等）。可能需要较长时间。完成后将自动开始下载，请勿关闭页面。期间界面会显示进度遮罩（含已打包文件数与体积、百分比）；中途点「取消」可停止等待，本次产物不会保留在服务器上。备份文件只会下载到你的设备，应用不会额外保存一份副本。

纯文本模式下不支持「导出 HTML」：HTML 导出依赖富文本渲染结果，此时会提示你先切回富文本模式，或改用「导出 .md」。

七、设置

顶栏「设置」打开设置面板，顶部为选项卡：
分区：管理现有分区（系统分区可隐藏、自建分区可删除，隐藏的分区可恢复），并在其中添加新的 NAS 目录作为分区。
文件：渲染模式（默认行为）、历史版本开关与保留数量、自动保存间隔，以及上传大小上限与格式黑名单。
安全：网络访问安全（信任反向代理、强制 Cookie Secure）与修改登录密码。
外观：暗黑模式、网页标题、网页图标（浏览器标签页）。
维护：导出 / 导入备份（配置 + 文档）、导出 / 导入配置（JSON）、「状态与日志」（应用状态 / 应用日志 / 登录日志），以及「卸载时是否清除软件数据」。
关于与帮助：使用指南、快捷键一览（与使用指南并列的「快捷键」按钮，均以弹窗打开）、开源协议与法律声明。

关于二次确认弹窗：删除文档、退出登录、导入备份、关闭安全选项等操作都会弹二次确认。这类弹窗的本意是劝退，因此「取消」是醒目的蓝色并排在右边，「确认」为白色排在左边——若你只是想看看发生了什么，直接点「取消」即可。

八、账号与访问

首次进入需设置管理员密码，之后凭密码访问。忘记密码：请在 fnOS 终端中执行命令 vditor reset-password，按指引重置密码。连续多次输错会触发临时锁定。

访问方式：本应用默认使用 3838 端口，在局域网内通过 http://局域网IP:3838 访问（将 IP 换成本机局域网 IP）。同时监听 IPv4 与 IPv6：局域网 IPv6 用 http://[局域网IPv6]:3838 访问（IPv6 地址需用方括号包裹）；使用 DDNS 域名且解析到 IPv6（AAAA 记录）时同样可正常访问。本应用为纯 HTTP 服务、不提供 HTTPS，无法用 https:// 直接访问（这与是否开启 Cookie Secure 无关）。

公网访问与风险：安装后默认禁止以 公网IP/域名:3838 的形式从公网直接访问（公网 IPv4 与公网 IPv6 均在内）。如确需公网访问，请在「设置 → 安全 → 网络访问安全」中关闭「强制 Cookie Secure 标记」；关闭后公网 HTTP 可正常访问，但登录密码与全部文档内容以明文传输，易被第三方截获，安全性显著降低，强烈不建议这么做，请自行评估并承担相应风险。更推荐使用反向代理 / 内网穿透，在公网侧启用 HTTPS 后再转发到本应用（此时请保持「强制 Cookie Secure 标记」与「信任反向代理」两项开启）。

可在「设置 → 维护 → 状态与日志 → 应用状态」中确认当前监听地址与客户端 IP（IPv4 / IPv6），以排查访问问题。

九、字数统计（顶栏）

正文：渲染后读者实际看到的文字数（不含 Markdown 标记）；含语法：Markdown 源文件字符数（磁盘实际大小）；预计阅读时间：正文字数 ÷ 400（字/分钟，向上取整），仅作粗略参考。超大文档下正文字数为采样估算值，详见上文「纯文本模式与大文档」。
