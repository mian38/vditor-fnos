# Vditor 移动客户端（Android）· 安装与使用说明

对应服务端版本：**v1.2.0**（移动端 API 15 个接口已实装）
接口规范与字段定义见 [`docs/MOBILE_API.md`](../docs/MOBILE_API.md)。

---

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 最低系统版本 | **Android 7.0（API 24）** |
| 目标系统版本 | Android 14（API 34） |
| 架构 | 全部（armeabi-v7a / arm64-v8a / x86 / x86_64，纯 Kotlin 无 native 库） |
| 网络 | 能访问 Vditor 服务器：局域网同网段，或公网域名 |
| 服务端 | Vditor **1.2.0 或更高**（1.1.x 无 `/api/m/` 路由，App 会提示接口不存在） |

> **服务端必须 ≥ 1.2.0。** 1.1.4 及更早版本没有移动端接口，
> 用本App 连接会稳定返回「接口不存在」。

## 2. 安装

### 2.1 直接安装 APK

1. 把 `.apk` 传到手机（数据线 / 微信文件传输 / 网盘均可）。
2. 在文件管理器里点击该文件。
3. 首次安装会提示「禁止安装未知应用」——按提示进入
   **设置 → 应用 → 特殊应用权限 → 安装未知应用**，
   允许你使用的那个文件管理器/浏览器「安装应用」。
4. 返回后点击 `.apk`，点「安装」。

### 2.2 用 adb 安装（推荐，适合折腾向）

```bash
adb install -r Vditor-1.2.0-release.apk
```

`-r` 表示覆盖安装同包名的旧版本（**签名必须一致**才能覆盖，签名不同需先卸载）。

### 2.3 从源码构建

```bash
cd android
./build_apk.sh              # debug + release
./build_apk.sh release      # 仅 release
```

脚本默认使用 `C:\android-toolchain` 下的工具链（JDK 17 + Android SDK 34 + Gradle 8.7），
可用环境变量 `VDITOR_TOOLCHAIN` 覆盖。

## 3. 登录

### 3.1 两种地址形式

| 场景 | 填什么 | App 会做什么 |
| --- | --- | --- |
| 局域网 | `192.168.1.10:9000`<br>`10.0.0.5`（不写端口也行） | 自动补 `http://`，无端口时补默认端口 **9000** |
| 公网 | `vditor.example.com`<br>`https://vditor.example.com` | 不写 scheme 时自动补 `https://` |
| 完整 URL | `http://192.168.1.10:9000`<br>`https://x.com/vditor/` | 原样使用 |

再填 **Web 端设置的同一个访问密码**，点「登录」。

### 3.2 记住地址

- 勾选「记住地址（不保存密码）」：**只存地址，不存密码**。
  下次打开自动填好地址，只需输密码。
- 登录过的地址会进入「最近使用」（最多 5 条），点一下即可填入。
- 取消勾选并成功登录一次，会清空地址与历史记录。

> **为什么不存密码**：把访问密码写进 `SharedPreferences` 意味着任何拿到
> root/备份的路径都能读到。地址是半公开信息，密码不是。这个取舍是刻意的。

### 3.3 会话有效期

与 Web 端一致：空闲 30 分钟 / 绝对 8 小时。超时会自动跳回登录页。

## 5. 多端同时编辑：乐观锁

App 在打开文档时记下服务端的 `version`，保存时原样回传。

若这期间**另一台设备/浏览器已经改过同一篇**，服务端会拒绝本次保存并返回
「保存冲突」，App 弹窗让你选择：

- **重新加载** — 拉取最新内容（你当前的输入会丢失，弹窗已明示）
- **放弃修改** — 直接退出该文档

App **绝不会**在你不知情的情况下用本地内容覆盖服务端。

## 6. 异常状态处理

| 状态 | 表现 | 恢复方式 |
| --- | --- | --- |
| 加载中 | 居中转圈 | 自动 |
| 空列表 | 插画 +「点右下角新建」 | 点 FAB |
| 连接失败 | 错误提示 + 「重试」按钮 | 点重试 |
| 断网 | 同上，附「检查与服务器的连接」 | 恢复网络后重试 |
| token 失效 | 自动跳登录页 | 重新输密码 |
| 保存冲突 | 弹窗二选一 | 见 §5 |
| 上传被拒 | 提示原因（黑名单 / 超限） | 换文件，或在浏览器端放开限制 |
| 服务器未初始化 | 提示去浏览器完成首次设置 | — |

**断线重连策略**：网络类瞬时故障（超时、连接重置）自动重试 3 次，
间隔 600ms → 1.2s 指数退避；4xx 这类确定性失败**不重试**（重试只会拖慢反馈）。

## 7. 权限清单

| 权限 | 是否必需 | 用途 |
| --- | --- | --- |
| `INTERNET` | **必需** | 访问 Vditor 服务器 |
| `ACCESS_NETWORK_STATE` | **必需** | 判断网络是否可用，给出准确提示 |
| `READ_EXTERNAL_STORAGE`（仅 ≤ Android 12） | 可选 | 旧系统上读取你选中的附件；**Android 13+ 不再需要**（系统选择器自带授权） |
| 摄像头 / 麦克风 | **未申请** | 不需要 |

**实际只在「上传附件」那一刻可能弹一次权限**（仅 Android 12 及以下）。
不点上传就不会有任何权限请求。

> 应用**不收集任何数据**：没有分析 SDK、没有崩溃上报、没有广告。
> 唯一的本地存储是 SharedPreferences（地址 + 主题 + 分区选择），
> 且已在 `backup_rules.xml` / `data_extraction_rules.xml` 中排除，不参与云备份。

## 8. 响应式与深色模式

| 维度 | 实现 |
| --- | --- |
| 断点 | `values/`（手机：16dp 边距、16sp 正文）与 `values-sw600dp/`（平板：40dp 边距、18sp 正文）两档 |
| 平板 | 列表与编辑区自动加宽留白，不做拉伸变形；无折叠屏专用布局 |
| 深色模式 | 跟随系统（`DayNight` 主题 + `values-night/` 色板），标题栏图标自动反色 |
| 横屏 | 正常适配（`adjustResize`，键盘弹出不遮挡输入区） |
| 字体缩放 | 用 `sp` 而非 `dp`，尊重系统字体大小设置 |

**无障碍**：

- 装饰性图标标 `importantForAccessibility="no"`，不污染读屏。
- 错误/状态提示用 `accessibilityLiveRegion="polite"`，读屏会主动播报。
- 「更多」按钮的 `contentDescription` 带上文件名（如「读书笔记.md 的更多操作」），
  多条目时读屏也能分清。
- 版本列表项把「时间 + 操作」合成一句完整描述，而非孤立读两个控件。
- 列表项标题用 `accessibilityHeading`，支持按标题快速跳转（TalkBack）。

## 9. 已知限制

1. **必须服务端 ≥ 1.2.0**，否则所有接口 404。
2. **纯源码编辑，无实时预览**。这是刻意的取舍：内嵌完整 Vditor 会让
   APK 从 ~4MB 涨到 ~20MB，且移动端富文本交互远不如浏览器顺手。
   需要预览时用浏览器端。
3. **TLS 校验被放宽**。为了兼容自签证书的内网 HTTPS，App 放行了证书链校验。
   **仅适用于你自己的局域网/私有域名**；若用它访问公网不可信站点会失去中间人防护。
4. **上传为单请求直传**，没有分片断点续传。大文件（数百 MB）在弱网下失败需手动重试。
5. **没有离线队列**。断网时不能编辑，恢复网络后需重新打开文档。
6. **不保存密码**，每次冷启动需重新输入（见 §3.2）。
7. **附件不支持单独删除或重命名**，随文档一起处理。
8. **未做多语言**。资源只保留中文与英文，默认中文。
9. **不支持 Android TV / Wear OS**（触屏形态，无对应布局）。

## 10. 隐私与数据

- 所有数据留在你的 NAS 上，App 不经过任何第三方服务器。
- 唯一出网连接是你填的那个地址。
- 卸载即彻底清除：无后台服务、无自启动、无遥测。

## 11. 构建签名

| 变体 | applicationId | 签名 |
| --- | --- | --- |
| debug | `com.mian38.vditor.debug` | 自动生成 debug keystore |
| release | `com.mian38.vditor` | 通过环境变量注入的发布 keystore |

发布签名**不随仓库分发**，通过以下环境变量传入：

```
VDITOR_KEYSTORE   keystore 文件绝对路径
VDITOR_STORE_PASS keystore 密码
VDITOR_KEY_ALIAS  key alias
VDITOR_KEY_PASS   key 密码
```

未配置时 release 仍可产出 **unsigned** 包（可安装测试，但**无法覆盖升级**
已用正式签名安装的版本——签名不一致时 Android 会拒绝安装，需先卸载）。

release 构建启用了 `minifyEnabled` + `shrinkResources`（R8 混淆与资源压缩），
`proguard-rules.pro` 保留 `data.**` / `net.**` 模型类与注解属性。
